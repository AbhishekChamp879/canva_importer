# Design IR V1

## Why the IR exists

`DesignDocumentV1` is the stable contract between acquisition/reconstruction and Figma rendering. It prevents browser DOM details or raw OpenAI output from becoming Figma API instructions.

```text
Canva screenshot + hints
        ↓
OCR and layout evidence
        ↓
ReconstructedPage (small untrusted schema)
        ↓
deterministic normalization
        ↓
DesignDocumentV1 (strict validated contract)
        ↓
Figma renderer
```

The authoritative source model is `canva_converter/models.py`. `schemas/design-document-v1.schema.json` is generated by `scripts/export_schema.py`; do not hand-edit the schema.

## Document shape

```json
{
  "schemaVersion": 1,
  "id": "document-id",
  "title": "Design title",
  "sourceUrl": "https://www.canva.com/design/ID/TOKEN/view",
  "createdAt": "2026-08-24T12:00:00Z",
  "pages": [],
  "assets": {}
}
```

Rules:

- `schemaVersion` is exactly `1`.
- At least one page is required.
- `sourceUrl` must be a Canva design/share URL, not an arbitrary URL.
- `createdAt` must be timezone-aware ISO 8601.
- Page IDs and all recursively nested node IDs are unique across the document.
- Every referenced asset exists and every asset-map key equals the asset's own ID.
- Total decoded embedded assets cannot exceed 512 MB.

## Pages

Each page contains:

| Field | Meaning |
| --- | --- |
| `id`, `name` | stable identity and Figma frame name |
| `width`, `height` | logical dimensions, each ≤32,768 in the IR |
| `orientation` | derived portrait, landscape, or square |
| `background` | optional solid or image fill |
| `children` | root nodes, maximum 5,000 including descendants |
| `qaReferenceAssetId` | required complete-page reference image |
| `metrics` | reconstruction and visual-QA measurements |

`orientation` must agree with the dimensions. The QA reference asset must have `source: "reference"`.

## Common node fields

Every node has:

- `id` and `type`;
- optional `name`;
- `box: {x, y, width, height}`;
- `rotation`, `opacity`, `visible`, and `locked`;
- integer `zIndex`;
- `confidence` from 0 to 1;
- `source: {canvaId?, sourceType, extraction}`.

Coordinates for root nodes are page-relative. Child coordinates are group-relative. Width and height must be positive. Numeric values cannot be NaN or infinite.

`source.extraction` is one of `dom`, `ocr`, `vision`, `asset`, or `fallback`. This records provenance for debugging; it is not a security decision.

Nodes may also carry `typeConfidence`, `geometryConfidence`, `styleConfidence`, and `hierarchyConfidence`. These optional scores preserve property-level reconstruction evidence; legacy producers may omit them and fall back to the node's aggregate `confidence`.

## Node types

### Group

- Requires `children`, including an empty array if necessary.
- Is the only node type allowed to contain children.
- Renders to a Figma frame with no visible fill. Optional `clipsContent` enables rectangular child clipping; omitted/false preserves the previous V1 behavior.

### Text

- Requires `text` and one or more `runs`.
- Runs must be ordered, contiguous, nonempty, within the string, and cover the entire string.
- Supports family, style, size, color/alpha, letter spacing, line height, decoration, horizontal alignment, and vertical alignment.
- CSS font stacks are normalized to one deterministic family before entering the IR.
- The renderer tries compatible style aliases and same-family Regular/Italic before substituting Inter, and reports every substitution.

### Image

- Requires `fill` of type image.
- Supports fill, fit, crop, and tile scale modes plus optional image transform.
- Crop transforms are bounded finite 2×3 affine matrices and are applied only with Figma crop mode.
- Renders as a Figma rectangle with an image paint.

### Rectangle and ellipse

- Require at least one fill.
- Support solid, image, linear-gradient, and radial-gradient fills plus an optional stroke.
- Rectangle supports corner radius.

### Vector

- Requires an SVG string.
- The SVG must be well-formed with an `svg` root.
- Safe `g`, `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, and gradient-definition primitives are accepted, including compound groups.
- Scripts, animation, filters, masks, text, embedded images, foreign objects, event handlers, external/data/javascript hrefs, external CSS imports, and external paint URLs are rejected or preserved regionally as pixels during reconstruction.
- Renders through `figma.createNodeFromSvg`.

### Raster fallback

- Requires `assetId` and human-readable `reason`.
- Preserves unsupported/low-confidence pixels in their source z-order.
- Renders as an image rectangle plus a small warning label when possible.
- Stores the reason as Figma plugin data.

## Fills, colors, strokes, and assets

Color channels are normalized 0–1 RGBA.

Solid fill:

```json
{"type": "solid", "color": {"r": 1, "g": 1, "b": 1, "a": 1}}
```

Image fill:

```json
{"type": "image", "assetId": "asset-1", "scaleMode": "fill"}
```

Linear gradient:

```json
{
  "type": "linear-gradient",
  "stops": [
    {"position": 0, "color": {"r": 1, "g": 0, "b": 0, "a": 1}},
    {"position": 1, "color": {"r": 0, "g": 0, "b": 1, "a": 1}}
  ],
  "transform": [[1, 0, 0], [0, 1, 0]]
}
```

Optional node effects support bounded `drop-shadow` and `layer-blur` values. Incomplete or complex effect evidence is not approximated as native styling; reconstruction emits a labelled regional raster fallback.

Stroke contains `color`, nonnegative `weight` up to 100, and inside/outside/center alignment. Figma support varies by node; the renderer applies supported values best effort.

An asset contains:

- `id`;
- `mimeType`: PNG, JPEG, or GIF;
- exactly one of `dataBase64` or `url`;
- optional dimensions;
- `source`: Canva, crop, or reference.

Embedded assets are limited to 25 MB decoded and must match the declared MIME signature. Completed job API responses replace embedded data with expiring localhost URLs.

## Quality metrics

| Metric | Meaning |
| --- | --- |
| `nativeCoverage` | estimated union area not represented by raster fallback |
| `fallbackCoverage` | union area covered by fallback nodes |
| `exactTextRate` | normalized sequence similarity between OCR full text and emitted text |
| `visualSimilarity` | 1 minus normalized pixel difference on comparable backend-rendered regions |
| `pixelDifference` | normalized mean pixel error on comparable regions |
| `missingRegionRate` | source foreground estimated outside represented coverage |
| `duplicateTextBlocks` | overlapping equal-text node count |
| `missingFonts` | provider/backend-known unavailable fonts; renderer adds actual Figma failures |
| `warnings` | page-specific quality/fallback notes |

`nativeCoverage + fallbackCoverage` cannot exceed 1. Text and vector pixels are excluded from raw backend pixel comparison because Pillow cannot reproduce Figma typography/SVG rendering. They remain part of coverage and text-specific checks.

## Reconstruction conversion rules

`ReconstructedPage` is intentionally smaller than the IR. Normalization:

1. Scales screenshot-pixel coordinates into logical Canva coordinates.
2. Clips elements to page bounds and removes impossible regions.
3. Uniquifies IDs.
4. Removes invalid parents and breaks cycles.
5. Deduplicates overlapping layout elements and OCR blocks.
6. Samples shape/background colors from source pixels.
7. Converts confident supported shapes to native nodes.
8. Crops image, unsupported, low-confidence, and invalid-vector regions.
9. Uses OCR as final text content and geometry.
10. Builds group-relative coordinates and deterministic z-order.
11. Adds a full-page QA reference asset.
12. Validates the complete `DesignDocumentV1`.

The confidence threshold for native visual conversion is currently 0.68.

## Versioning

V1 is strict: unknown fields are rejected. Additive fields therefore still require a schema/model update and renderer decision. Breaking semantics or new node families should use Design IR V2 rather than silently changing V1.

When changing V1:

1. Update Pydantic models.
2. Update reconstruction output.
3. Update the Figma renderer.
4. Add model and renderer tests.
5. Run `python -m scripts.export_schema`.
6. Verify the schema drift test and all consumers.
